# ✦ AstraPad

> A tiny macropad for a very specific Linux problem.

**Stardance page:** https://stardance.hackclub.com/@phantom-ascii/

If you've used the Linux terminal, you've probably noticed that `Ctrl + C` and `Ctrl + V` don't work like they do everywhere else.

Instead you get:

`Ctrl + Shift + C` to copy
`Ctrl + Shift + V` to paste

It's not a massive problem, but when you're using the terminal constantly, reaching for that extra `Shift` gets annoying.

So I decided to build a little hardware solution.

## What is it?

AstraPad is a custom 4-key macropad with:

* 4 shortcut buttons
* 2 rotary encoders
* OLED display
* XIAO RP2040
* Custom PCB
* Custom 3D-printed case

One encoder handles volume + mute, while the other controls brightness.

## Why?

I use Linux a lot and got tired of reaching for `Ctrl + Shift` every time I wanted to copy or paste in the terminal.

So instead of complaining about it, I decided to build something.

## Building it

I'm designing everything from scratch using KiCad and FreeCAD, then writing the firmware myself.

This is my first proper PCB project, so things will probably break.

That's part of it.
