# AstraPad Firmware

AstraPad uses KMK firmware running on a Seeed XIAO RP2040.

## Controls

- SW1 — Ctrl + Shift + C
- SW2 — Ctrl + Shift + V
- SW3 — Ctrl + C
- SW4 — Ctrl + V
- ROT1 — Volume
- ROT1 press — Mute
- ROT2 — Brightness
- OLED — Volume/Brightness status

## Status

Firmware is currently being developed and will be tested once the XIAO RP2040 arrives.
